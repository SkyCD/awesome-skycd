# Awesome SkyCD

A curated directory of community plugin sources for [SkyCD](https://github.com/SkyCD/SkyCD).

[`plugins.json`](plugins.json) contains HTTPS URLs for publisher-owned manifests. Each publisher owns its NuGet feed and release history. The directory starts empty while the publishing contract and first reference plugin are being prepared.
